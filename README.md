# Paradise Nursery - Shopping Application

Paradise Nursery is an e-commerce React web application for browsing and purchasing houseplants.

## Features
- **Landing Page**: Responsive home screen with an overview and "Get Started" call-to-action.
- **Product Listing**: 18 houseplants organized across 3 categories with details and images.
- **Shopping Cart**: Real-time updates for cart count, total cost calculations, quantity modifications, and item removal powered by Redux Toolkit.

## Tech Stack
- React.js
- Redux Toolkit
- CSS3
